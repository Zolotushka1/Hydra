# Values this repository contains on purpose, each scoped to the file it is in.
#
# Format: path<TAB>value
#
# Scoping is the point. The x25519 test vector is legitimate in the test that
# verifies key derivation and is a leak in config.json; a global allowance
# cannot tell those apart.
#
# An entry whose value no longer appears in the file it names fails this check.
# A permission nobody can point at is not a permission — it is a line that reads,
# six months later, as though someone decided the value was fine.
#
# Adding an entry is a decision about one value in one file. Widening
# scripts/secret-canaries.txt to make a finding disappear is not the same thing
# and is not the fix.

# The x25519 public key from verifying Reality key generation against
# `xray x25519`. A published test vector, not material for any deployment.

# specifies, and this one is the test vector that goes with the key above.
