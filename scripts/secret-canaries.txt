# Canaries for secret material. One list, two consumers.
#
# The golden secret guard in panel-core reads this file, and so does
# scripts/check-tracked-files.sh. A second copy would drift from the first, and
# that is not hypothetical: `subscription_token` was already a canary for the
# golden documents when three of them were committed to this repository inside
# users.json. The project knew the string was secret; the knowledge lived in one
# place and the leak happened in another.
#
# Lines are `kind value`. Blank lines and lines starting with # are ignored.
#
#   key      a field name whose assigned value is credential material. Matched
#            as a substring of the key, so `subscription_token` matches `token`.
#   literal  text that is credential material wherever it appears.

key token
key secret
key password
key private_key
key hash
key hmac
key credential

# The PEM delimiter, not the words. `assert!(!body.contains("PRIVATE KEY"))` is a
# guard doing its job; `-----BEGIN` is a key.
literal -----BEGIN
